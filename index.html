          Mit GitHub verbinden

          Deine eigene Liste wird in deinem GitHub-Repository gespeichert, damit sie auf allen Geräten gleich ist. Dafür braucht die Website auf jedem Gerät einmal einen GitHub-Schlüssel. Er darf nur Dateien in diesem Repository ändern und bleibt in diesem Browser.

          1. Schlüssel bei GitHub erstellen. Name und Berechtigung sind schon ausgefüllt.
          2. Bei Repository access „Only select repositories“ wählen und dieses Repository auswählen.
          3. Unten auf Generate token tippen, den Schlüssel kopieren und hier einfügen.
